# Frame Flow Counter / Kareye bağlı sayaç

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/frame-flow-counter/).

Debi değerini 30 FPS zaman çizelgesinden hesapla.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- İlk değer
- Son değer
- FPS

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Animate a flow reading between two values at a selected frame rate.

Open [the live tool](https://omerbek.github.io/frame-flow-counter/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
